Title: Montgomery Fleet Equipment Inventory Analysis — This project uses a Pivot Table to analyze and summarize the distribution of fleet equipment across different departments and equipment classes.

Dataset: Montgomery Fleet Equipment Inventory Dataset — The dataset contains 1,582 equipment units across 49 records, providing insights into how fleet resources are distributed within the organization.

Tools Used: Microsoft Excel and Pivot Tables.

Key Finding: The Transportation Department manages the largest share of the fleet, with 1,221 equipment units, making it the department with the highest concentration of inventory.
