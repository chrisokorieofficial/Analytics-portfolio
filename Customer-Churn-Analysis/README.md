Title: Customer Churn Analysis — This project analyzes customer cancellation patterns to identify the factors and behaviors associated with customer churn.

Dataset: The dataset contains 7,043 customer records and 39 variables, including customer demographics, tenure, contracts, services, revenue, and churn information.

Tools Used: Microsoft Excel, Excel formulas and functions, Pivot Tables, and data visualizations.

Key Finding: 1,869 customers churned (26.5%), with Month-to-Month contracts showing the highest number of cancellations, while competitor offers and better devices were among the leading reasons for churn.
